# patches/members-pagination

**These two files are not ours.** They are the patches Takenori TAKAKI
(user:takenory) attached to [#43355](https://www.redmine.org/issues/43355) on
2026-08-05, downloaded unchanged from
`https://www.redmine.org/attachments/download/36564/` and `/36565/` and
committed here so a later revision of them can be diffed against what we
tested.

Both apply cleanly to `origin/master` r24882 (`2563fa6a5`, 2026-08-03).

There is no patch of ours in this directory, and there will not be one: the
framework's decision for this feature is to hang on to #43355 rather than to
submit a competing patch. The one improvement we found (see *The finding* in
`../../docs/features/members-pagination/dossier.md`) is a diff on top of these
two files, so it cannot apply standalone to a pristine trunk and INV-2 keeps it
out of this directory. It lives in the dossier as text, ready to paste into a
note.
